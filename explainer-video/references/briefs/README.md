# Subagent briefs

Fill in the <placeholders> and pass the text as the Agent prompt with `model: sonnet` and `run_in_background: true`. Launch the asset agents (narrator, illustrator, audio) in one message so they run in parallel. Animators start once `PLAN.md`, the illustration table, the kit and estimated timing exist. Every brief names the files the agent owns; keep those sets disjoint.
