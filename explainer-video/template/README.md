# {{TITLE}}: rebuild guide

A deterministic HTML canvas film: every frame is a pure function of time, every beat is keyed to a spoken word, so a new narration re-times the animation by itself. Run everything from this folder. One-time computer setup: `bash <skill>/scripts/setup_runtime.sh` (puppeteer-core and a Python venv live in `~/.video-runtime`, outside the project).

Files you edit: `project.json` (settings), `script/narration.md` (the script, `## N Title` chapters), `js/scenes/*.js` (animation), `assets/illus/jobs.json` (illustration prompts), `PLAN.md` (the brief). Look: `js/theme.js` (palette, font, logo, style). Spend: `spend.log` and `spend.json` (hard stop from `project.json` budget). `tools/py.mjs <script.py>` runs a Python tool with the configured interpreter.

## Commands, in order

```bash
# 0. Timing estimate from the script (animators can start now); preview: open index.html in Chrome
node tools/est-timing.mjs

# 1. Voice (paid): audition, pick the voice in project.json, record per chapter, time, align
node tools/list-voices.mjs                 # free: voice ids to review/voices.json
node tools/tts-audition.mjs                # optional, paid: judge candidate voices on the real script
node tools/tts.mjs a                       # one take per chapter (existing files are skipped); redo one: delete it, then node tools/tts.mjs a 3
node tools/words.mjs a                     # word timestamps from two speech-to-text models
node tools/align.mjs a                     # builds assets/audio/vo/vo.wav and js/vo-timing.js (per-chapter take: node tools/align.mjs a 6=b)
node tools/py.mjs snap_onsets.py           # snaps sentence starts to real sound onsets

# 2. Illustrations (paid): hero first, then variants (jobs.json refs), then cut-outs
node tools/gen-illus.mjs hero
node tools/gen-illus.mjs character_one character_one_happy
node tools/py.mjs cutout.py assets/raw/illus/hero.png assets/illus/hero.png    # repeat per image

# 3. Music (paid, only if the project needs its own bed) and effects
node tools/gen-music.mjs cartoon_marimba   # Veo clip audio, music.prompts in project.json
node tools/py.mjs music_cartoon.py         # loop and ending at music.bpm and music.key
node tools/py.mjs sfx_make.py              # optional: rebuilds the 11 shipped effects

# 4. Check the picture on the real timing
node tools/cues.mjs "some phrase"          # chapter starts, cues, scenes, music direction, errors
node tools/storyboard.mjs review/storyboard   # one still per beat plus layout lint (review/storyboard/lint.txt)
node tools/py.mjs contact.py review/storyboard review/sheet_   # contact sheets with the spoken words

# 5. Audio and captions
node tools/export-cues.mjs                 # assets/audio/cues.json (film length, chapters, music grid, sound effects)
node tools/py.mjs mix.py                   # mix.wav, mix.m4a, stems; -16 LUFS, limiter at -2.5 dBFS sample peak
node tools/captions.mjs                    # captions.srt and captions.vtt (42 characters per line at most)

# 6. Render and automated QA
node tools/render-par.mjs --workers=8      # the MP4 named in project.json "output", with soft subtitles
node tools/qa-auto.mjs <the mp4>           # durations, loudness, clicks, layout lint, sync check

# 7. AI reviews (paid, at most three rounds; verify every claim on the frame or waveform)
node tools/review-frames.mjs review/frames.md
node tools/review-video.mjs <the mp4> review/video.md
node tools/listen-mix.mjs <mix.mp3> review/audio.md
```

Quick test without audio: `node tools/render-par.mjs --to=4 --no-subs --silent test.mp4`. Spend so far: `node tools/eden.mjs spent`.

## Rules of the engine

- No `Date`, no `Math.random` (use `K.rng(seed)`), no state between frames. Never hardcode times: `S.cue('phrase')`.
- Colours only through `K.PAL` roles (`ink, primary, accent, highlight, bg, surface, line, accentTint, bgTint, muted`; legacy aliases still work).
- `js/project-config.js` and the scene script tags in `index.html` are regenerated by the tools; run any tool (or `node tools/config.mjs`) after editing `project.json` or adding a scene file.
- Read `ANIMATOR_BRIEF.md` before writing scenes.
